============================================================
  PFX 変換ツール（MT5 / Wine 用）  PfxConvert  v1.1.1
============================================================

  English manual: Manual_EN.txt（同梱の英語版の説明書）

■ このツールについて

  MT5 を Linux（Ubuntu など）上で Wine を使って動かすと、ブローカーから
  受け取った SSL 証明書（.pfx）を読み込めず、ログインできないことがあります。
  このツールは、PFX ファイルを Wine 上の MT5 で読み込める形式に変換します。

    変換後の形式: 秘密鍵 3DES / 証明書は暗号化なし / MAC SHA1（反復 2048 回）

  動作確認: 外為ファイネスト（FXTF）の MT5 / Ubuntu / Wine 10.0
  （この形式のファイルでログインできることを確認しています。他のブローカーや
    Wine のバージョンでは確認していません。）


■ 動作環境

  ・Windows 10 / 11
  ・インストール不要です。PfxConvert.exe だけで動きます。
    （Windows に標準で入っている .NET Framework 4.x を使います）


■ 使い方

  1. PfxConvert.exe をダブルクリックして起動します。

  2. 証明書の PFX ファイルを、画面の点線の枠にドラッグ＆ドロップします。
     ・PfxConvert.exe のアイコンに直接ドロップしても使えます。
     ・枠をクリックしてファイルを選ぶこともできます。

  3. パスワード入力画面で、証明書の「元のパスワード」を入力して
     「変換する」を押します。
     ・パスワードを変えたい場合は「新しいパスワードを設定する」に
       チェックを入れ、新しいパスワードを 2 回入力します。
     ・パスワードが違うときは、その画面のまま入力し直せます。

  4. 元のファイルと同じ場所に「PFX変換済み」フォルダ（英語表示では「PFX_converted」）が作られ、
     変換したファイルが保存されて、フォルダが自動で開きます。
       ファイル名: 元の名前_3DES-SHA1-certNONE.pfx

  5. 変換したファイルを MT5 の証明書フォルダに置きます。
     置き場所は次の「MT5 での証明書の置き場所」を見てください。
     パスワードは手順 3 のもの（変更しなかった場合は元のパスワード）です。


■ 表示言語（日本語 / English）

  ・OS の表示言語が日本語なら日本語で、それ以外なら英語で起動します。
  ・画面の右上のリンク（「English」または「日本語」）で、いつでも切り替えられます。
    選んだ言語は保存されないので、次に起動したときは OS の表示言語に戻ります。
  ・保存先のフォルダ名は、日本語表示のときは「PFX変換済み」、英語表示のときは
    「PFX_converted」です。


■ MT5 での証明書の置き場所
  MetaQuotes の公式ヘルプでは、証明書ファイル（*.pfx）は、MT5 のデータフォルダの
  中の Config\certificates フォルダに置くことになっています。
  変換したファイルを、そのフォルダにコピーしてください。

  【Windows 版 MT5 の場合】

    MT5 のメニュー「ファイル」→「データフォルダを開く」で開いたフォルダの中の
      Config\certificates
    通常のインストールでは、次のような場所です。
      C:\Users\<ユーザー名>\AppData\Roaming\MetaQuotes\Terminal\<英数字の長い名前>\Config\certificates
    ※ MT5 を /portable オプションで起動している場合は、MT5 のインストール
      フォルダの中の Config\certificates です。

  【Linux（Wine）版 MT5 の場合】

    MetaQuotes 公式のインストールスクリプト（mt5linux.sh）を使うと、Wine の領域は
    ホームディレクトリの .mt5 フォルダ（~/.mt5）の下に作られます。公式ヘルプでは、
    MT5 の既定の場所は次のとおりです。
      ~/.mt5/drive_c/Program Files/MetaTrader 5
    ただし、Windows 版と同じように、Wine のユーザーフォルダの下がデータフォルダに
    なる場合もあります。
      ~/.mt5/drive_c/users/<ユーザー名>/AppData/Roaming/MetaQuotes/Terminal/<英数字の長い名前>
    場所が分からないときは、端末で次のコマンドを実行すると、証明書フォルダを
    探せます。
      find ~/.mt5 ~/.wine -type d -ipath '*/config/certificates' 2>/dev/null
    表示されたフォルダに、変換したファイルをコピーします。複数見つかったときは、
    実際に使っている MT5 のものを選んでください。
    何も表示されないときは、MT5 の Config フォルダの中に「certificates」という名前の
    フォルダを作って、そこにコピーしてください。

  【置いたあと】

    ・ファイル名は変換後のまま（元の名前_3DES-SHA1-certNONE.pfx）で構いません。
      ただし、名前の先頭（元の名前の部分）は変えないでください。MetaQuotes の
      公式ヘルプでは、証明書のファイル名は「口座番号_会社の略称_名前.pfx」
      （Login_ID_Name.pfx）の形とされています。MT5 がファイル名を照合に使うか
      どうかは公式ヘルプに書かれていませんが、念のため先頭の口座番号は
      そのまま残してください。
    ・変換前の元のファイルは、certificates フォルダに残さず、別の場所に保管して
      ください。元のファイルが入ったままだと、MT5 のログに
      「loading of standard SSL certificate from PFX failed」と出ることがあります。
    ・MT5 を一度終了して起動し直し、ログインを試してください。証明書の
      パスワードを求められたら、手順 3 で設定したパスワードを入力します。


■ パスワードについて

  ・新しいパスワードは「半角英数字と記号」だけにしてください。
    Wine は全角文字などを含むパスワードを正しく扱えません。
  ・空のパスワードは読み込めない原因になるので避けてください。
  ・MetaQuotes の公式ヘルプでは、証明書のパスワードは 5 文字以上で、英小文字・
    大文字・数字のうち 2 種類以上を含むこととされています。新しいパスワードを
    設定するときは、これに合わせると無難です。
  ・変換前のファイルも変換後のファイルも、パスワードを知っている人なら
    ログインに使えます。ファイルとパスワードは他人に渡さないでください。


■ 安全性について

  ・インターネットには接続しません。証明書やパスワードを外部に送りません。
  ・変換はメモリ上で行い、設定ファイルやログファイルは作りません。
  ・元のファイルは変更しません（別のフォルダに新しいファイルを作ります）。
  ・変換後も秘密鍵はパスワードで暗号化されています。
  ・変換後は、新しいパスワードで読み直せることを自動で確認しています。
  ・変換後のファイル名には、元の名前がそのまま残ります。元の名前に口座番号や
    名前が含まれていると、変換後のファイル名や画面のログにも表示されます。
    画面のスクリーンショットを人に見せるときは注意してください。


■ 初めて起動したときに警告が出る場合

  インターネットから入手した EXE には署名がないため、
  「Windows によって PC が保護されました」と表示されることがあります。
  「詳細情報」→「実行」を押すと起動できます。

  または、PfxConvert.exe を右クリック →「プロパティ」→ 下の方の
  「許可する」にチェック →「OK」でも警告が出なくなります。


■ うまくいかないとき

  ・「パスワードが違います」
      元のパスワードを確認してください。大文字・小文字、半角・全角に注意。

  ・「秘密鍵が含まれていません」
      ログイン用の証明書ファイルではありません。
      ブローカーから受け取った PFX ファイルか確認してください。

  ・「ファイルが空（0 バイト）です」
      ダウンロードに失敗しています。ダウンロードし直してください。

  ・変換したファイルでも MT5 にログインできない
      Linux の端末から MT5 を起動すると、エラーの理由が表示されます。
        cd "MT5 のインストールフォルダ"
        WINEDEBUG=warn+crypt wine terminal64.exe 2>&1 | grep -iE "gnutls|crypt|pfx"

      Wine と同じ仕組み（gnutls）で読めるかを事前に確認することもできます。
        sudo apt install gnutls-bin
        certtool --p12-info --inder --infile 変換したファイル.pfx


■ 読み込める元ファイルの形式

  ・暗号: RC2-40 / RC2-128 / 3DES / AES-128・192・256（PBES2）
  ・MAC: SHA1 / SHA256 / SHA384 / SHA512 / なし
  ・Java などで作られた BER 形式のファイルにも対応しています。
  ・鍵は RSA のみです。
