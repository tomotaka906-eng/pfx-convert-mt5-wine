============================================================
  PFX Converter for MT5 on Wine  (PfxConvert)  v1.1.1
============================================================

  日本語の説明書: 説明書.txt (Japanese manual)

[ What this tool does ]

  When you run MetaTrader 5 on Linux (Ubuntu, etc.) under Wine, the SSL client
  certificate (.pfx) issued by your broker may fail to load, and you cannot log in.
  This tool converts a PFX file into a format that MT5 under Wine can load.

    Output format: private key 3DES / certificate NOT encrypted / MAC SHA1
                   (2048 iterations)

  Tested with: the MT5 of Gaitame Finest (FXTF) on Ubuntu with Wine 10.0.
  A file in this format let the author log in. Other brokers and other Wine
  versions have not been tested.


[ Requirements ]

  - Windows 10 / 11
  - No installation. PfxConvert.exe is the only file you need.
    (It uses .NET Framework 4.x, which is built into Windows.)
  - The window is available in English and Japanese (see "Language" below).


[ How to use ]

  1. Double-click PfxConvert.exe.

  2. Drag and drop your PFX file onto the dotted frame in the window.
     - You can also drop the file onto the PfxConvert.exe icon.
     - Or click the frame to choose the file.

  3. In the password dialog, enter the ORIGINAL password of the certificate and
     click "Convert".
     - To change the password, tick "Set a new password" and enter the new
       password twice.
     - If the password is wrong, the dialog shows an error and lets you retry.

  4. A folder named "PFX_converted" ("PFX変換済み" when the window is in Japanese) is
     created next to the original file, the converted file is saved in it, and the
     folder opens automatically.
       File name: <original name>_3DES-SHA1-certNONE.pfx

  5. Put the converted file in the MT5 certificate folder. See the next section.
     The password is the one from step 3 (the original password if you did not
     change it).


[ Language ]

  - The window opens in Japanese if Windows is displayed in Japanese, and in English
    otherwise.
  - Click the link at the top right ("English" / "日本語") to switch at any time. The
    choice is not saved, so the next start follows the Windows display language again.

[ Where to put the file in MT5 ]

  According to the MetaQuotes help, certificate files (*.pfx) go into the
  Config\certificates folder inside the MT5 data folder. Copy the converted file there.

  Windows MT5:

    In MT5, choose File -> Open Data Folder, then open
      Config\certificates
    For a normal installation this is typically:
      C:\Users\<user>\AppData\Roaming\MetaQuotes\Terminal\<long hex name>\Config\certificates
    If MT5 is started with the /portable option, it is Config\certificates inside
    the MT5 installation folder instead.

  Linux (Wine) MT5:

    With the official MetaQuotes install script (mt5linux.sh), the Wine prefix is
    created in ~/.mt5. The default location of MT5 given in the MetaQuotes help is:
      ~/.mt5/drive_c/Program Files/MetaTrader 5
    As on Windows, the data folder may instead be under the Wine user profile:
      ~/.mt5/drive_c/users/<user>/AppData/Roaming/MetaQuotes/Terminal/<long hex name>
    If you are not sure, find the certificate folder in a terminal:
      find ~/.mt5 ~/.wine -type d -ipath '*/config/certificates' 2>/dev/null
    Copy the converted file into the folder that is printed. If several are
    printed, choose the one that belongs to the MT5 you actually use.
    If nothing is printed, create a folder named "certificates" inside the MT5
    Config folder and copy the file there.

  After copying:

    - You can keep the file name as it is (<original name>_3DES-SHA1-certNONE.pfx).
      Do not change the first part (the original name). The MetaQuotes help says
      certificate files are named "Login_ID_Name.pfx" (account number, short name
      of the broker, client name). The help does not say whether MT5 uses the file
      name to match the account, but keep the account number at the start to be
      safe.
    - Do not leave the ORIGINAL (unconverted) PFX in the certificates folder; keep it
      somewhere else. If it stays there, the MT5 log may show
      "loading of standard SSL certificate from PFX failed".
    - Restart MT5 and try to log in. If MT5 asks for the certificate password,
      enter the one from step 3.


[ About passwords ]

  - Use only half-width letters, digits and symbols (ASCII) for a new password.
    Wine does not handle passwords with non-ASCII characters correctly.
  - Avoid an empty password; it is a common reason a file cannot be loaded.
  - The MetaQuotes help says a certificate password must be at least 5 characters
    and contain at least two kinds of characters among lower case, upper case and
    digits. Following this when you set a new password is a safe choice.
  - Anyone who has the file and its password can log in with it. Do not share
    either of them.


[ Safety ]

  - The tool never connects to the internet and never sends your certificate or
    password anywhere.
  - Conversion happens in memory. No settings file or log file is written.
  - The original file is not modified (a new file is created in another folder).
  - The private key in the converted file is still protected by the password.
  - After conversion, the tool re-reads the new file with the new password to
    check it automatically.
  - The converted file keeps the original name. If the original name contains
    your account number or your name, they also appear in the converted file name
    and in the log in the window. Take care when you share screenshots.


[ Warning on first launch ]

  The EXE is not code-signed, so Windows may show "Windows protected your PC"
  (SmartScreen) for a file downloaded from the internet. Click "More info" ->
  "Run anyway".
  Alternatively: right-click PfxConvert.exe -> Properties -> tick "Unblock" at the
  bottom -> OK.
  If you prefer not to run an unsigned EXE, read the source code and build it
  yourself with build.bat (see the GitHub repository).


[ Troubleshooting ]

  Messages you may see:

  "Wrong password."
      Check the original password (case, half/full width).
  "Could not decrypt. The password is wrong or the file is damaged."
      Same as above, or the file is damaged.
  "The file contains no private key. ..."
      It is not a login certificate. Check that it is the PFX file you received
      from your broker.
  "The file is empty (0 bytes). The download may have failed."
      Download the file again.
  "This is not a PFX (PKCS#12) file."
      Check that you chose the right file.
  "The two new-password entries do not match."
      Type the same new password in both boxes.
  The converted file still does not work in MT5?
      Start MT5 from a terminal to see why it fails:
        cd "<MT5 folder>"
        WINEDEBUG=warn+crypt wine terminal64.exe 2>&1 | grep -iE "gnutls|crypt|pfx"

      You can also check whether gnutls (what Wine uses) can read the file:
        sudo apt install gnutls-bin
        certtool --p12-info --inder --infile converted-file.pfx


[ Supported input files ]

  - Encryption: RC2-40 / RC2-128 / 3DES / AES-128, 192, 256 (PBES2)
  - MAC: SHA1 / SHA256 / SHA384 / SHA512 / none
  - BER-encoded files (for example, made by Java) are supported.
  - RSA keys only.
